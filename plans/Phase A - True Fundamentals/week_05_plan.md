# Week 5 Plan: Cloud & Environment Fundamentals

## Overview

- **Phase:** A — True Fundamentals
- **Focus:** Orientation before specialization
- **Goal:** Understand what a cloud project actually is, how billing/IAM work, and what a container is conceptually — so Week 6 (BigQuery) isn't your first contact with "the cloud" as an idea
- **Anki Target:** 25 cards

---

## Monday–Friday

### Daily Objectives

- **Monday:** What is a cloud provider — projects/accounts, regions, the console vs. the CLI → Deliverable: GCP free-tier account created, `gcloud` CLI installed and authenticated
- **Tuesday:** IAM basics — users, roles, service accounts, principle of least privilege → Deliverable: 1 service account created with a scoped-down custom role (not "Owner")
- **Wednesday:** Billing awareness — how cloud costs actually accrue, setting a budget alert → Deliverable: budget alert configured on your free-tier project
- **Thursday:** What is a container, conceptually — the problem Docker solves, images vs. containers (no building yet, just running `docker run hello-world` and understanding what happened) → Deliverable: 1-paragraph explanation in your own words of why containers exist
- **Friday:** Cloud storage basics — buckets/objects, uploading and reading a file via CLI and via a Python script → Deliverable: 1 script that uploads a local CSV to cloud storage and reads it back
