# Week 34 Plan: Portfolio, Resume & Retrospective

## Overview

- **Phase:** L — Capstone II & Job Readiness (final week of the 8-month arc)
- **Focus:** Presenting what you've built, and planning what comes next
- **Goal:** Turn 34 weeks of work into a portfolio and resume someone else can understand in two minutes, and write the retrospective that feeds your 12-month plan
- **Anki Target:** 10 cards (this week is about presentation and reflection)

---

## Monday-Friday

### Daily Objectives

- **Monday:** GitHub profile and repo polish. Pin both Flagship projects, write a profile README linking to them with a one-line description of what each demonstrates, and clean up each repo (clear README, setup steps that work from a fresh clone, architecture diagram at the top) → Deliverable: both Flagship repos pass a "fresh clone" test, where you follow your own README on a clean setup and it works
- **Tuesday:** Resume draft. Describe projects by outcome and decision, not tool lists (for example, "cut query cost by partitioning and clustering" instead of "used BigQuery") → Deliverable: 1-page resume draft with 3-4 project bullets that each name a problem, an action, and a result
- **Wednesday:** Write one technical article about something you actually built. Good candidates: the Spark vs. Flink comparison (Week 28), the managed vs. self-hosted comparison (Week 26), or an idempotent backfill lesson (Week 13) → Deliverable: 1 published or publish-ready article of 800-1500 words
- **Thursday:** Gap audit. Go through `skill_tree.md` and mark each skill as Solid, Shaky, or Not yet touched. Be honest; this list drives the next trial → Deliverable: annotated skill tree with a short list of the 5 weakest areas
- **Friday:** Full retrospective of Weeks 1-34. What worked, what was too slow, what was too fast, which resources were worth it, which weren't → Deliverable: written retrospective, plus a first draft of priorities for the 12-month trial

### Anki Targets

- 10 cards total this week, tagged `review::final`, focused on whichever areas the gap audit flags as Shaky
