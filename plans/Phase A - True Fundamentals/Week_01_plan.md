# Week 1 Plan: SQL Fundamentals I (SELECT, Filtering, Aggregation)
 
## Overview
 
- **Phase:** A — True Fundamentals
- **Focus:** Core single-table SQL
- **Goal:** Build fluent, unhesitating command of SELECT, WHERE, GROUP BY, and aggregate functions before touching anything more complex
- **Anki Target:** 30 cards
- **Why this week exists:** The original plan opened with window functions and CTEs — powerful, but built on a foundation (basic filtering/aggregation) that was never taught. This week is that foundation.
---
 
## Monday–Friday
 
### Daily Objectives
 
- **Monday:** Relational model basics (tables, rows, columns, primary/foreign keys), SELECT + WHERE, comparison/logical operators → Deliverable: 8 queries against a sample dataset (e.g. a free Kaggle CSV loaded into SQLite/DuckDB)
- **Tuesday:** ORDER BY, LIMIT, DISTINCT, handling NULLs (IS NULL, COALESCE) → Deliverable: 6 queries demonstrating NULL-safe filtering
- **Wednesday:** Aggregate functions (COUNT, SUM, AVG, MIN, MAX), GROUP BY → Deliverable: 6 grouped-aggregate queries
- **Thursday:** HAVING vs WHERE, combining filters with aggregation, CASE WHEN for conditional logic → Deliverable: 5 queries using CASE WHEN inside aggregations
- **Friday:** Timed drill — 15 varied SELECT/WHERE/GROUP BY problems solved without notes, self-graded → Deliverable: drill results + list of any concepts still shaky
